# 目录说明

服务器项目：/hpc2hdd/home/haoyuetian/datapath_logic。

src/ 保存自研算法；当前为空。tools/ 保存实际使用的 Yosys、ABC、安装程序与构建依赖。
baselines/yosys_abc/ 记录当前入口的上游来源和指标定义；baselines/logic/ 与 baselines/extraction/ 保存外部研究方法。

benchmarks/rtl/ 保存公开 RTL 数据，包括原始 5000 个 MutexShare 用例；benchmarks/extraction/ 保存图提取数据。
ref/problem/ 保存原题图片，ref/papers/ 与 ref/patents/ 保存原始文献，ref/docs/ 保存上游资料。
ref/frameworks/ 保存 XLS、CIRCT、OpenSTA 参考源码；ref/flows/ 保存公开流程参考源码。它们不参与当前 run.py。
ref/metadata/ 保存原始下载包与来源记录，ref/SOURCES.json 记录资料路径、URL 和校验值。

run/ 仅保存当前入口新生成的结果。figure/ 统一保存 SVG 电路图。
当前入口与用法见根目录 README.md。
